## Configuration Overview

This directory contains system and infrastructure configuration files used in the virtualization lab
environment.

## Components

- QEMU/KVM virtualization settings
- Network bridge configurations
- Docker runtime configuration
- VM resource allocation profile

## Purpose

To ensure reproducibilty of the lab environment across:
- Nested virtualization setups
- Container workloads
- Network bridge Configurations

## Notes

Configuration are optimized for a multi-layer virtualization architecture running on Linux Host System.
