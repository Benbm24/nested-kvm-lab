## Nested KVM LAB

This project demonstrates nested virtualization using  Linux QEMU/KVM,  bar  metal  installed  Linux OS as
Host machine , running Windows 11 Pro Education/Developer(version) as guest virtual machine, with addional 
nested Virtual Machines and Containers running inside the Windows 11 Pro and Kali-Linux Vertual Machines.
Specifically in the Kali-Linux Vertual Machine running containers inside it , demonstrating nested 
containerized workloads within nested vertualization environments.
Vertual Machines are considered one of the core technologies behind modern cloud computing infrastructure.
They provide workload isolation, flexible ressources provisioning , scalability and improving security
bounderies between operating systems and services.

This Lab was built to study:
  - Nested Virtualisation
  - Virtual machine provisioning
  - Nested container environments
  - Ressource Allocation
  - CPU Memory Storage and Network behaviour
  - Real-Time virtualization monitoring
  - Infrastructure experimentation using Linux 	qemu/kvm
  - Virtual Bridges.
